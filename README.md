Práctica de aplicación de estándares de codificación en Java.

## Parte II: Identificación de errores

| N | Error encontrado | Corrección propuesta |
|---|-------------------|----------------------|
| 1 | El nombre de la clase `producto` comienza con minúscula. | Cambiarlo a `Producto`. |
| 2 | La variable `CODIGO` no sigue la convención camelCase. | Cambiarla a `codigo`. |
| 3 | La variable `Nombre` comienza con mayúscula. | Cambiarla a `nombre`. |
| 4 | La variable `Precio` comienza con mayúscula. | Cambiarla a `precio`. |
| 5 | Los atributos son públicos y no existe encapsulamiento. | Declarar los atributos como `private`. |
| 6 | Los parámetros `c`, `n` y `p` no son descriptivos. | Usar `codigo`, `nombre` y `precio`. |
| 7 | El método `Mostrar()` comienza con mayúscula. | Cambiarlo a `mostrar()`. |
| 8 | El código no tiene una sangría adecuada. | Aplicar sangría consistente dentro de la clase y los métodos. |
| 9 | Faltan espacios adecuados entre elementos del código. | Aplicar espacios según el estándar de Java. |
| 10 | El formato general dificulta la lectura del código. | Utilizar un formato uniforme y nombres descriptivos. |
